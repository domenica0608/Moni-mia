# Moni Mia
### Organiza tu dinero

Moni Mia es una plataforma web de organización financiera personal diseñada para ayudar principalmente a jóvenes y estudiantes a administrar mejor su dinero, controlar sus gastos y desarrollar hábitos de ahorro.

## Aplicación publicada

Puedes ingresar a Moni Mia desde el siguiente enlace:

https://domenica0608.github.io/Moni-mia/

## Funcionalidades principales

- Registro y organización de ingresos.
- Control de gastos personales.
- Organización de metas de ahorro.
- Asistente financiero con inteligencia artificial para resolver dudas y recibir consejos.
- Formulario de contacto para enviar consultas.
- Panel administrativo con inicio de sesión.
- Visualización y consulta de mensajes recibidos.

## Estructura del proyecto

- `index.html`: página principal.
- `admin.html`: panel administrativo.
- `css/`: archivos de estilos.
- `js/`: funcionalidades de JavaScript.
- `assets/`: recursos gráficos.
- `backend/`: servidor, rutas, modelos y conexión con MongoDB.

## Ejecución local

Para ejecutar el proyecto en un entorno local:

1. Clonar el repositorio de GitHub.
2. Entrar a la carpeta `backend`.
3. Instalar las dependencias con `npm install`.
4. Configurar las variables de entorno en un archivo `.env`.
5. Iniciar el servidor con `node server.js`.
6. Abrir el archivo `index.html` desde un servidor local.

## Seguridad

Las credenciales, claves de API y variables privadas se almacenan mediante variables de entorno y no deben publicarse en GitHub.
