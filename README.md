# Moni Mia 
### Organiza tu dinero

Moni Mia es una plataforma web de organización financiera personal diseñada para ayudar a los jóvenes a administrar mejor su dinero.

## Funcionalidades

- Registro y organización de ingresos.
- Control de gastos.
- Organización de metas de ahorro.
- Formulario de contacto.
- Panel administrativo con inicio de sesión.
- Consulta de mensajes recibidos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- MongoDB Atlas
- Mongoose

## Estructura del proyecto

- `index.html`: página principal.
- `admin.html`: panel administrativo.
- `css/`: estilos de la página.
- `js/`: funcionalidades de JavaScript.
- `assets/`: recursos gráficos.
- `backend/`: servidor y conexión con MongoDB.

## Ejecución local

Para iniciar el backend:

1. Entrar a la carpeta `backend`.
2. Instalar las dependencias con `npm install`.
3. Configurar las variables de entorno en un archivo `.env`.
4. Iniciar el servidor con `node server.js`.

**Importante:** las credenciales y variables privadas no deben publicarse en GitHub.
